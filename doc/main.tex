\begin{abstract}
  This document describes the installation and use of the webamc
  python package that allows to submit and view latex AMC (Auto
  Multiple Choice, \url{https://www.auto-multiple-choice.net/}) MCQ
  through a web interface. The webamc package consists of:
  \begin{itemize}
  \item a command-line tool allowing to compile latex MCQ ;
  \item and a web interface allowing to load compiled MCQ in a database
    and view them.
  \end{itemize}
\end{abstract}
