This section lists the different configuration parameters of a webamc
configuration. By default, the configuration is stored in:
\begin{itemize}
\item \file{\$HOME/.local/share/webamc/config.json} on unix like
  systems
\item \file{\$HOME/AppData/Roaming/webamc} on windows systems
\end{itemize}

Parameters may alter either the web interface ; or the command-line
interface (cli) tool ; or both. This is marked with a checkmark or a
cross in the list below.
