Le titre est facultatif. Il apparaît dans les copies annotées (i.e., corrigées) et dans la boîte de réception des étudiantes. À défaut, le code du projet est utilisé.

Le nombre de copies détermine le nombre d'exemplaire du sujet qui sera généré. Si ce paramètre n'est pas renseigné, le nombre de copies est calculé à partir des groupes sélectionnés. Si aucun de ces deux paramètres n'est renseigné, la génération du sujet n'est pas possible.

Le seuil est compris entre 0 et 1. Plus sa valeur est petite et plus l'outil est sensible à la présence de pixels dans une case pour déterminer si celle-ci a été effectivement cochée. Par exemple, avec une valeur de 1, il faut que la case ait été intégralement noircie pour être considérée comme cochée. À défaut, le seuil utilisé est 0.5.

L'identifiant étudiant est celui attribué au code étudiant (macro AMCcode ou AMCcodeGridInt) dans le code tex. Ce paramètre doit être ignoré si votre QMC est au format AMC-TXT ou si l'association entre étudiantes et copies n'est pas faite automatiquement.

L'attribut détermine l'information d'identification renseignée par l'étudiante dans sa copie. Ce paramètre doit être ignoré si l'association entre étudiantes et copies n'est pas faite automatiquement.

Lors de l'association entre étudiantes et copies ou du calcul du nombre de copies à générer (si ce paramètre n'est pas renseigné), la liste des étudiantes est construite à partir des groupes sélectionnés. Sélectionnez un groupe dans la liste pour l'ajouter à la liste des groupes sélectionnés. Cliquez sur un groupe pour le retirer de cette liste.
