Vous devez sélectionner une archive zip obtenue avec l'outil webamc compile. Tous les éléments (QCMs et questions) inclus dans l'archive seront insérés dans votre base de données.

Toutes les questions de l'archive qui ne sont pas rattachées à un QCM seront considérées comme autonomes, c'est-à-dire qu'elles pourront apparaître dans un pack de questions.

Les QCMs se trouvant dans l'archive seront par défaut en mode examen et donc invisibles pour les autres utilisatrices. Vous pourrez ensuite créer un examen dans le menu de même nom.

Un QCM peut aussi être passé en mode révision à partir de la page base de données. Vous devrez ensuite sélectionner le (ou les) groupe(s) d'étudiantes pour le(s)quel(s) le QCM sera visible.
