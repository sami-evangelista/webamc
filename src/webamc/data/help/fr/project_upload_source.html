La source du QCM doit être:
  • un fichier texte (d'extension .txt) ;
  • ou un fichier tex (d'extension .tex) ;
  • ou une archive (d'extension .zip).

Si la source est un fichier texte, celui-ci doit contenir votre QCM au format AMC-TXT.

Si la source est un fichier tex, celui doit contenir l'intégralité du code tex de votre QCM (i.e., sans référence à d'autres fichiers tex, image, fichier de style, ...).

Enfin, si vous fournissez une archive, celle-ci doit impérativement contenir un répertoire tex/ et un fichier tex/main.tex contenant le code de votre QCM avec, éventuellement, des références vers d'autres fichiers de l'archive se trouvant dans le répertoire tex/. Le QCM doit être compilé correctement si l'on compile le fichier main.tex à l'intérieur du répertoire tex.
