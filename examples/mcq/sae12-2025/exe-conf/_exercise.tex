On souhaite dans la suite configurer le réseau pour que les deux PC
puissent communiquer. On fait les hypothèses suivantes:
\begin{itemize}
\item Après activation des interfaces eth0, PC1 reçoit l'IP 1.1.1.1/24 et
  PC2 reçoit l'IP 1.1.2.1/24.
\item Les deux interfaces du routeur ont la dernière IP disponible sur
  leurs réseaux respectifs.
\end{itemize}
